---
title: Ave Maria
description: Um último turno para impedir uma vitória.
---

Quando um jogador ganha, o jogador seguinte ainda tem um turno. Nesse turno, ele pode fazer o que quiser com a vitória: impedi-la, ou deixá-la acontecer. Se ele não puder fazer nada, o jogador ganha.

Ele pode até usar o turno para proteger a vitória, por exemplo jogando uma carta qualquer para que ninguém possa jogar **Impermanence** nela.

<Callout title="Exemplo">
1. P1 ganha.
2. P2 joga um 3 verde.
3. P3 joga Impermanence.
4. A Impermanence cancela o 3 verde, e não a vitória. P1 vence.
</Callout>
